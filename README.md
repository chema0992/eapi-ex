# 🚀 EAPI 확장 프로그램 (EAPI Extension)

> **기존의 번거로웠던 5단계 유저스크립트 설치 과정은 이제 그만! 확장 프로그램 하나로 클릭 한 번에 모든 모듈을 간편하게 사용하세요.**  
> 클릭 한 번으로 설치하고 강력한 커스텀 비공식 블록을 활성화할 수 있습니다.

🌐 **[공식 웹사이트 바로가기](https://eapi-web.pages.dev)** | 📦 **[메인 EAPI 코어 레포지토리](https://github.com/chema0992/EAPI)**

---

## ✨ 주요 기능
- 🎨 **WebGL 1.0**: 엔트리 작품 내 3D 그래픽 및 셰이더 연산 지원
- ⚡ **WASM 로더**: C/C++/Rust 등으로 작성된 WebAssembly 바이너리를 웹 주소로 불러오고 실행
- 🎵 **WebAudio**: 실시간 음향 합성, 주파수 분석 및 고성능 오디오 처리
- ⚙️ **WebWorker**: 백그라운드 멀티스레딩 연산으로 렉 없는 게임 구현
- 💾 **IndexedDB**: 대용량 게임 데이터 및 세이브 파일 영구 저장

---

## 📥 설치 방법

1. 우측 [Releases](https://github.com/chema0992/eapi-ex/releases)에서 최신 `eapi-extension.zip` 파일을 다운로드하거나, 초록색 **Code**를 클릭하고 Download Zip을 누르세요.
2. 다운로드한 zip 파일의 압축을 풉니다.
3. 브라우저 주소창에 `chrome://extensions` 또는 `whale://extensions`를 입력하거나 확장앱 관리 메뉴로 들어갑니다.
4. 우측 상단의 **개발자 모드**를 켭니다.
5. **압축해제된 확장 프로그램을 로드/설치** 버튼을 누르고, 압축을 푼 폴더를 선택합니다.

---

## 🎛️ 사용 방법
1. 브라우저 우측 상단 툴바에서 **EAPI 확장 프로그램 아이콘(E)**을 클릭합니다.
2. 사용하고 싶은 블록 모듈(WebGL, WASM 등)의 **스위치를 토글(ON)**합니다.
3. 엔트리 페이지를 새로고침하면 적용이 완료됩니다!

---

## 🏆 EAPI 프로젝트가 이룬 성과
- 👀 **저장하고 다시 불러와도 남아있는 블록**: EAPI EX v1.1.0을 시작으로 리메이크를 눌러도 블록이 남아있습니다. 이제 편하게 쓰세요!
- 🎨 **엔트리 최초 3D/셰이더 지원**: WebGL 1.0 모듈을 통해 엔트리 작품 내 3D 그래픽 구현
- ⚡ **고성능 연산 실현**: WASM 및 WebWorker 도입으로 복잡한 게임 로직과 멀티스레딩 지원
- 💾 **영구 데이터 저장**: IndexedDB를 통한 대용량 게임 세이브 데이터 관리
- **그 외 블록들까지**: 차후 다른 블록들도 업데이트 될 예정입니다
- **저장부터 공유까지**: 콘솔로 신기함만 보는건 그만! 저장까지 하세요. 작품 상세 페이지에서 실행!

## 🔄 기존 버전(유저스크립트) 대비 달라진 점
| 구분 | 기존 EAPI (Tampermonkey) | **EAPI Extension (확장 프로그램)** |
| :--- | :--- | :--- |
| **설치 방식** | 5단계 복잡한 설치 | **클릭 몇 번으로 간편 설치** |
| **모듈 설정** | 스크립트 코드 직접 수정 | **팝업 UI 스위치로 토글** |
| **UI** | 다소 투박한 TamperMonkey의 UI | **더욱 나아진 UI** |

> 📜 더 자세한 기술 스펙 및 코어 개발 기록은 **[EAPI Core 레포지토리](https://github.com/chema0992/EAPI)**에서 확인하실 수 있습니다.
